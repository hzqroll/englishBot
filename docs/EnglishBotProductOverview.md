# EnglishBot 当前产品功能说明书

## 文档说明

- 文档定位：当前版本产品能力盘点与功能边界说明
- 最后更新：2026-04-08（V1.1 — 命令路由优化）

## 1. 产品定位

EnglishBot 是一个面向群聊场景的英语学习机器人，当前支持 QQ 群和飞书群双渠道运行。

当前产品不是单一的翻译工具，而是一个带有两条能力主线的群聊学习产品：

- 核心训练营主线
  - 围绕“主题学习包 -> 群内真实使用 -> 即时纠错 -> 晚间反馈 -> 次日回捞 -> 周度复盘”组织持续学习
- 内容增强支线
  - 通过每日 `Friends` 对话推送，补充轻量输入、词汇积累、语法解析和文化背景
- 运营与运维支撑
  - 通过定时任务、管理后台、消息投递日志和飞书文档归档支持持续运营

这意味着当前产品已经不是单一“聊天翻译机器人”，而是一个带训练闭环和内容运营能力的英语学习系统。

## 2. 核心训练营主线

### 2.1 `@机器人` 即时语言支持

群成员在群里 `@机器人` 发送消息时，系统会根据内容类型自动分流：

- 中文消息
  - 默认走腾讯翻译，返回英文结果
- 英文消息
  - 默认走英文纠错，返回修正后的英文、中文释义、问题说明和错误点
- `大模型润色：<对话内容>`
  - 对显式提供的整段对话做一次整体分析
  - 输出保留说话人结构的英文版对话和按人归类的问题说明
- `分析最近聊天内容`
  - 对最近累计的群聊内容做一次整体分析
  - 输出英文版对话和问题说明

`@机器人` 不发送内容时会显示简洁的使用引导（发英文→纠错 | 发中文→翻译）。

整体分析属于高成本功能，和普通翻译、纠错分开使用。

### 2.2 固定学习命令

学习命令默认直接在群里发送，不需要 `@机器人`。

当前支持的固定命令有：

- `报名学习`
  - 把当前用户加入训练营，并初始化等级
- `今日任务`
  - 获取当天学习包和任务卡片
- `提交任务 <任务ID> <内容>`
  - 提交当天任务，获得分数、反馈和积分
- `复习一下`
  - 拉取当前到期的复习项
- `我的等级`
  - 查看当前等级、活跃度和相关学习证据
- `开始周测`
  - 生成一套属于当前用户的周测试卷
- `答题 <试卷ID> 1:A 2:B ...`
  - 提交整套周测答案，支持 `1:A`、`1：A`、`1.A`、`1A` 等格式
- `本周总结`
  - 获取本周个人学习周报
- `帮助`
  - 查看命令和使用说明（含每个命令的用途描述）

### 2.3 被动观察与整体分析

机器人默认会静默观察群里的普通发言，不会对每条消息主动插话。

被动观察当前承担的作用包括：

- 记录普通群聊消息
- 沉淀学习证据
- 识别当天是否使用了目标表达
- 为晚间学习进度总结提供素材
- 为“分析最近聊天内容”积累对话缓存

普通群聊消息不会直接触发回复，但会进入后续学习分析链路。

### 2.4 每日学习闭环

当前每日学习闭环由以下环节组成：

- 每日学习包
  - 系统每天围绕一个主题生成学习包，包含昨日回顾、核心词块、支持词汇、情景对话和任务清单
- 昨日回顾与次日回捞
  - 系统会把前一天的高频错误和重点表达插回下一天学习包，并尽量让任务再次复用
- 任务提交与反馈
  - 用户提交任务后，系统记录内容、计算分数、生成简短反馈并发放积分
- 错误沉淀与复习
  - 英文纠错结果会沉淀为错误点、错误出现记录和复习项，供后续回顾
- 等级评估
  - 当前提供 `beginner` / `intermediate` 两档等级，用户可通过 `我的等级` 主动刷新

### 2.5 周度闭环

当前周度闭环包括：

- 周测系统
  - 面向已报名用户，支持出题、答题、计分和错题回流
- 周报
  - 汇总学习天数、完成率、纠错次数、周测成绩、薄弱点和总结语
- 晚间总结
  - 每日错误整理和每日学习进度只面向已报名用户生成

## 3. 内容增强支线：每日 Friends 对话

### 3.1 功能定位

`Friends` 功能是当前新增的内容增强支线，不直接替代训练营主线，而是补充一条更轻量的英语输入与讲解路径。

它的目标包括：

- 提供稳定的英文对话素材
- 增加词汇、语法和文化背景输入
- 提高飞书群内的日常学习活跃度
- 为长期留档和复盘提供更适合文档化的内容

### 3.2 当前输出内容

系统每天会从本地 `Friends` 台词资源中选取一个对话片段，并生成一张结构化学习卡。

当前卡片内容包括：

- `Dialogue`
  - 原始对话片段
- `中文翻译`
  - 逐句中文翻译
- `重点词汇`
  - 3-5 个重点词汇或短语，附释义和例句
- `语法解析`
  - 1-2 个语法点
- `文化背景`
  - 如有需要则补充背景说明

当未配置大模型能力时，系统当前只会输出原始对话片段，不会生成翻译和解析内容。

### 3.3 推送与归档方式

`Friends` 功能当前通过独立定时任务 `daily_friends` 运行。

当前行为特点：

- 按配置中的 `friends.start_date` 和当日日期偏移，轮播选择对话片段
- 当前只向飞书已启用群广播
- 发送后可按集归档到独立的飞书文档
- 归档文档按 `SxxExx` 维度管理，便于后续回看

### 3.4 与主线学习系统的关系

`Friends` 功能当前属于“内容增强支线”，与主线训练营的关系如下：

- 不依赖 `报名学习`
  - 当前是群广播内容，不只面向已报名用户
- 不替代 `今日任务`
  - 不负责主线任务、周测、等级或晚间总结
- 更偏输入和讲解
  - 当前更适合轻学习、素材积累和文档沉淀

## 4. 自动化任务与消息推送

### 4.1 当前自动任务

系统当前共有 7 个自动任务：

- `daily_push`
  - 晨间推送今日学习包
- `daily_error_digest`
  - 晚间推送个人错误整理
- `daily_progress`
  - 晚间推送个人学习进度
- `weekly_report`
  - 周报推送
- `weekly_quiz`
  - 周测推送
- `nightly_backup`
  - 数据库备份
- `daily_friends`
  - 每日 Friends 对话推送

这些任务支持后台手动触发，也支持按 cron 动态调整执行时间。

### 4.2 推送对象

自动推送当前分为三类：

- 群广播内容
  - 例如每日学习包、每日 Friends 对话
- 个人定向内容
  - 例如错误整理、学习进度、周报、周测
- 文档归档内容
  - 飞书侧的周学习文档和 Friends 按集文档

### 4.3 飞书文档归档

当前飞书文档归档有两类：

- 主线训练营内容
  - 按周创建文档，自动追加每日任务、错误摘要、学习进度和周报
- Friends 内容
  - 按集创建文档，归档对应 `SxxExx` 对话学习卡

## 5. 多渠道与消息展示

### 5.1 支持渠道

当前产品支持：

- QQ 群
- 飞书群

两侧共同承接的能力包括：

- `@机器人` 即时语言支持
- 固定学习命令
- 被动群聊观察
- 主线定时任务推送

### 5.2 展示形态

系统当前有三种主要消息形态：

- 纯文本回复
  - 用于翻译、纠错、帮助说明、答题结果等
- QQ 图片卡片
  - 用于任务、周测、周报、晚间总结等结构化内容
- 飞书互动卡片
  - 飞书端对应的结构化学习卡片

### 5.3 当前渠道差异

当前渠道差异主要体现在接入方式和增强能力：

- QQ
  - 通过 OneBot 接入
  - 结构化内容优先渲染为图片卡片
- 飞书
  - 通过 WebSocket 接入
  - 结构化内容渲染为互动卡片
  - 额外支持飞书文档归档
  - 当前额外支持每日 Friends 对话推送

## 6. 管理后台与运维能力

### 6.1 管理后台入口

系统提供 Web 管理后台，当前主要入口包括：

- `/admin/login`
- `/admin`
- `/healthz`
- `/readyz`

### 6.2 后台核心页面

当前后台具备以下能力：

- 仪表盘
  - 查看整体指标和最近任务执行情况
- 用户列表
  - 查看用户基本数据
- 群组管理
  - 管理 QQ / 飞书群
  - 配置是否启用
  - 配置 QQ 管理群
  - 配置群级消息渲染模式
- 运行时设置
  - 查看和修改动态配置
  - 查看当前生效配置
- 作业记录
  - 查看定时任务执行情况
- 投递日志
  - 查看消息推送是否成功
- 调试页
  - 无需真实群聊即可测试翻译、纠错和部分消息处理流程

### 6.3 手动触发能力

后台当前支持手动触发以下任务：

- 每日学习包推送
- 每日纠错整理
- 每日学习进度
- 周报
- 周测
- 夜间备份
- 每日 Friends 对话推送

## 7. 数据沉淀与分析能力

系统当前不仅回复消息，也会把学习行为沉淀为结构化数据，供复习、总结、统计和后台展示使用。

当前主要沉淀对象包括：

- 消息事件
  - 记录群消息、`@机器人` 消息、命令消息
- 互动结果
  - 记录翻译、纠错、整体分析等结果
- 错误点与错误出现记录
  - 支持复习和统计高频问题
- 对话学习证据
  - 记录用户在普通群聊中的学习痕迹
- 复习项与次日回捞候选
  - 支持复习安排和昨日回顾
- 每日学习快照
  - 保存每日进度结论
- 卡片快照
  - 保存已生成的结构化卡片内容
- 周测会话与答案
  - 保存试卷、答题和分数
- 周报
  - 保存每周汇总结果
- 作业运行记录与投递日志
  - 记录任务执行和消息发送情况

## 8. 典型使用路径

### 8.1 报名用户的主线学习路径

一个典型的报名用户路径是：

1. 进入学习群
2. 发送 `报名学习`
3. 发送 `今日任务`
4. 完成并提交任务
5. 白天在群里使用英语，并在需要时 `@机器人`
6. 晚上接收错误整理和学习进度
7. 周末参与周测并查看周报

### 8.2 日常即时语言支持路径

群成员日常即时使用路径通常包括：

1. 需要中文转英文时 `@机器人` 发送中文
2. 需要英文纠错时 `@机器人` 发送英文
3. 需要复盘整段表达时 `@机器人` 发送 `大模型润色：<对话内容>`
4. 需要复盘近期群聊时 `@机器人` 发送 `分析最近聊天内容`

### 8.3 飞书群的 Friends 内容路径

飞书群中的 `Friends` 路径通常包括：

1. 系统定时推送当日 `Friends` 对话卡片
2. 群成员阅读原始对话、翻译、词汇和语法解析
3. 运营或用户通过飞书文档查看按集沉淀内容

### 8.4 管理员运维路径

管理员日常运维路径通常包括：

1. 登录后台查看仪表盘
2. 管理群组启用状态和配置
3. 调整运行时设置
4. 用调试页验证消息处理
5. 手动触发定时任务
6. 查看作业记录和投递日志排障

## 9. 当前边界与限制

当前版本需要明确的边界包括：

- 学习命令与 `@机器人` 分工不同
  - 学习命令默认直接发送，不需要 @机器人
  - `@机器人` 用于翻译、纠错、`大模型润色`和`分析最近聊天内容`
  - 用户 `@机器人` 后发送固定命令，系统会提示改为直接发送
- 晚间总结、周测、周报主要面向已报名用户
- `分析最近聊天内容` 依赖最近群聊缓存，并且有最小句数门槛
- 最近群聊缓存是进程内缓存
  - 服务重启后会重新累计
  - 跨天后会按新一天重新计算
- 周测当前仍以客观题为主
- `Friends` 当前属于可选开启能力
  - 需要在配置中显式启用
  - 当前只向飞书已启用群推送
- 未配置大模型时，`Friends` 只会输出原始对话，不会生成翻译和解析
- 外部服务未配置时，部分能力会走降级逻辑
  - 适合开发调试，不适合作为正式生产效果
- 当前产品核心场景仍然是群聊学习，不是私聊陪练产品

## 10. 文档使用建议

这份文档适合回答三类问题：

- 当前产品到底已经有哪些真实可用能力
- 某个功能属于主线训练营、内容增强支线还是后台运维能力
- 新需求进来后，应该挂到主线、支线还是运营体系

如果后续继续做产品规划，建议以本说明书为“当前版本基线”，再叠加路线图和专项迭代提案。
